# Automatic API Type Synchronization

## 🎯 Objective

Automatic system to generate frontend TypeScript interfaces from the backend OpenAPI spec, ensuring synchronization between backend and frontend.

## 🚀 How It Works

### Automatic (CI/CD)

The workflow `.github/workflows/sync-api-types.yml` is automatically triggered when there are changes in:
- `src/**/*.py` (backend code)
- `requirements.txt` (Python dependencies)

**Process:**
1. Spins up PostgreSQL + FastAPI temporarily
2. Runs Alembic migrations
3. Downloads the OpenAPI spec from `/openapi.json`
4. Generates TypeScript interfaces and Angular services in `frontend/src/app/api/`
5. Automatically commits if there are changes

**Monitored branches:** `main`, `addingNewAPIs`

### Manual (Local Development)

```bash
# 1. Start the backend
docker compose up

# 2. Run the script
./scripts/generate-api-types.sh
```

```
├── services/                  # Angular services
│   └── earthquakes.service.ts
└── ...
```

## 💻 Usage in Code

```typescript
import { EarthquakesService } from './api/services/earthquakes.service';
import { EarthquakeListResponse } from './api/models';

@Component({ ... })
export class MyComponent {
  constructor(private api: EarthquakesService) {}
  
  loadData() {
    this.api.listEarthquakes(1, 20).subscribe({
      next: (response: EarthquakeListResponse) => {
        console.log(response.data); // Type-safe!
      }
    });
  }
}
```

## ⚠️ Important

- **DO NOT edit** files in `frontend/src/app/api/` manually - they will be overwritten
- **Always commit** changes generated by CI/CD
- Breaking changes in the API will cause TypeScript errors in the frontend

## 🛠️ Configuration

- **Generator:** `@openapitools/openapi-generator-cli`
- **Template:** `typescript-angular`
- **Angular:** v21
- **Config:** `frontend/openapitools.json`

## 🐛 Troubleshooting

**Backend not running:**
```bash
docker compose up
```

**Missing dependencies:**
```bash
cd frontend && npm install
```

**Types not found:**
```bash
./scripts/generate-api-types.sh
```
